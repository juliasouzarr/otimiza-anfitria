# Otimiza Anfitriã

Sistema de gestão de aluguel de enxovais, controle de reservas, kits pré-montados e disponibilidade de estoque para anfitriões e hospedagens.

## Tecnologias
- PHP 8.2+ / Laravel 11
- Tailwind CSS & Alpine.js
- FullCalendar
- MySQL

## Funcionalidades
- **Gestão de Enxovais**: Cadastro de itens, categorias, tamanhos, valores unitários e controle de estoque físico e disponibilidade por período.
- **Kits de Enxoval**: Kits pré-montados (Solteiro, Casal, Queen, King) com composição detalhada, precificação e gerenciamento de status.
- **Pedidos & Reservas**: Criação rápida de pedidos com inserção de kits com multiplicador de quantidade, cálculo automático de subtotais e valor total, controle de status e encerramento automático após o prazo de devolução.
- **Dashboard & Calendário**: Visão geral com métricas, ocupação e calendário interativo de retiradas e devoluções.
